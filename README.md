# Akan Name Generator

Simple web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender. 

## Author

**Humphrey** - [GitHub Profile](https://github.com/humphrey-developer/akan-name-generator.git)

---

## Description

In Akan culture, children are named based on their gender and the day of the week they were born. This application takes a birthdate and gender input, calculates the exact day of the week using JavaScript date logic, and dynamically updates the UI with the corresponding name.
